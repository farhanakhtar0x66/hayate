# Hayate Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task. Steps use checkbox syntax for tracking.

**Goal:** Ship an installable directional flick Android keyboard and its GitHub repository.

**Architecture:** Pure Java gesture/layout/state core, native Canvas keyboard View, InputMethodService, and a native setup/practice/settings Activity. Shared rendering powers the IME and practice area. No runtime dependencies or network permission.

**Tech Stack:** Java 17 language level, JDK 21, Gradle 9.5, AGP 9.2.1, Android API 36, JUnit 4.

**Spec:** docs/superpowers/specs/2026-10-24-hayate-design.md

## Global constraints

- minSdk 26; targetSdk/compileSdk 36.
- Preserve supplied six-cluster directional Latin layout.
- No typing storage, network permission, or runtime third-party libraries.
- Private GitHub repo is the implementation default; v0.1 APK is signed with a private local release key.

## Review focus

- Cancel/multiple pointers must never commit stray text or continue deletion.
- Password, numeric, multiline and search fields must receive the correct behavior.
- Emoji, combining marks, selected text and cursor bounds must delete correctly.
- Setup state must refresh after returning from Android settings.
- Theme/font-size/orientation changes must preserve usable touch targets.
